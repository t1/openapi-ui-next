OpenAPI UI

Static, keyboard-navigable HTML from your OpenAPI spec

Explore the Petstore API

What's this?

This demo runs a tiny Quarkus petstore whose OpenAPI spec is picked up at build time by the openapi-ui-maven-plugin. The plugin generates a set of static HTML fragments — no client-side framework, no runtime code generation.

↓ Build-time generation

The Maven plugin reads your spec and writes plain HTML files. No JavaScript rendering at runtime.

⌃ Keyboard navigation

Arrow keys traverse the path tree. Enter expands, Escape collapses. Fully accessible with ARIA roles.

>_ Try, curl, httpie

Three interaction modes: send requests directly, or copy ready-made curl / httpie commands.

↔ Responsive layout

Side-by-side on desktop, stacked on mobile. Built on Bulma's column system.
