# Demo Quarkus App Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a minimal Quarkus petstore demo app that exercises the OpenAPI UI Maven plugin end-to-end.

**Architecture:** New `demo` module with JAX-RS endpoints, in-memory storage, and two Maven plugins chained: `smallrye-open-api-maven-plugin` generates `openapi.yaml` from compiled classes at `process-classes`, then `openapi-ui-maven-plugin` generates static HTML at `prepare-package`. Quarkus serves the generated UI as static resources.

**Tech Stack:** Quarkus 3.x, quarkus-rest, quarkus-smallrye-openapi, smallrye-open-api-maven-plugin, Java 21

**Spec:** `docs/superpowers/specs/2026-03-14-demo-app-design.md`

- [x] **Step 1: Create `PetResource.java`**

```java
package com.github.t1.openapi.ui.demo;

import jakarta.ws.rs.GET;
import jakarta.ws.rs.NotFoundException;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.PathParam;

import java.util.ArrayList;
import java.util.List;

@Path("/pets")
public class PetResource {
    private static final List<Pet> PETS = new ArrayList<>(List.of(
            new Pet(1, "Max", "available"),
            new Pet(2, "Bella", "adopted")
    ));

    @GET
    public List<Pet> list() {
        return PETS;
    }

    @GET
    @Path("/{id}")
    public Pet get(@PathParam("id") long id) {
        return PETS.stream()
                .filter(p -> p.id() == id).findFirst()
                .orElseThrow(NotFoundException::new);
    }
}
```

```java
package com.github.t1.openapi.ui.demo;

import io.quarkus.test.junit.QuarkusTest;
import org.junit.jupiter.api.Test;

import static io.restassured.RestAssured.given;
import static org.hamcrest.Matchers.*;

@QuarkusTest
class PetResourceTest {
    @Test
    void shouldListPets() {
        given()
                .when().get("/pets")
                .then()
                .statusCode(200)
                .body("$.size()", is(2))
                .body("[0].name", is("Max"))
                .body("[1].name", is("Bella"));
    }

    @Test
    void shouldGetPetById() {
        given()
                .when().get("/pets/1")
                .then()
                .statusCode(200)
                .body("name", is("Max"))
                .body("status", is("available"));
    }

    @Test
    void shouldReturn404ForUnknownPet() {
        given()
                .when().get("/pets/999")
                .then()
                .statusCode(404);
    }
}
```

- [x] **Step 4: Smoke-test: start the app and check the UI is served**

Run: `java -jar demo/target/quarkus-app/quarkus-run.jar &`
Then: `curl -s http://localhost:8080/openapi-ui/index.html | head -5`
Expected: HTML output starting with `<!DOCTYPE html>` or `<html>`.
Then: kill the background process.

- [x] **Step 5: If any step failed, debug and fix**

Common issues:
- If `openapi.yaml` is not generated: check `smallrye-open-api-maven-plugin` version and configuration.
  The plugin scans compiled classes, so it must run after `compile` phase. The `generate-schema` goal
  defaults to `process-classes` which is correct.
- If the UI is not served: check that `outputDirectory` points to `target/classes/META-INF/resources/openapi-ui`.
- If the build fails with plugin not found: ensure `mvn install` was run on the parent first
  (so `openapi-ui-maven-plugin` is in the local repo).
